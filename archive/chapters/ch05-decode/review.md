## 本轮已纠正的关键事实

- `Tasks::Decode` 在每轮开始时检查取消；它不能中断已经进入 `Run` 的当前 step。内部与外部采样是控制边界，不等同于设备侧与 CPU 侧执行位置。
- 基准模型的完整 float32 logits 为 1 MiB，但只有 CPU 采样器确实需要把设备数据复制到 host 时，这个字节数才构成额外传输；字节比例不能直接换算为时延比例。
- `TopPSampler` 以 `k == 1` 定义 greedy。temperature 为 0 时只是被钳到最小正数，不能据此把该配置定义为 greedy；附录 D 的结果只说明测试配置在相同 seed 下复现了相同输出。
- 停止序列按原始 token id 匹配。部分前缀先暂存，后续失配时释放暂存前缀并发送当前文本；完整命中时不发送暂存前缀与触发 token。
- 尚不能形成完整文本的 BPE token id 会暂存后合并解码；停止检测先读取本轮原始 id，再执行 BPE 合并。无可发送文本的 step 不触发 `kProcessing` 回调。
- `Softmax` 中的零和与无穷和分支是防御性路径；代码没有在该处显式拒绝 NaN 或无穷 logits，不能据此保证任意输入都会得到合法概率分布。

## 当前仍存在的实验缺口

- 原规划的停止序列部分匹配运行实验没有独立日志；当前结论来自冻结源码、配套测试与时序推演。
- 温度与 seed 实验只提供少量输出观察，未形成分布级统计，也不能估计不同采样参数的稳定差异。
- 尚未在同一模型、后端与设备上隔离测量 CPU 采样和设备侧采样的数据传输与单步时延。
